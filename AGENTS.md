# Agent Guidelines for Secure-Team

- Whenever code changes, bug fixes, or new features are implemented in this repository, always stage, commit, and push them to GitHub (`https://github.com/rg3889005-lab/Secure-Team` on branch `main`).
- Never stage or commit sensitive configuration files (`.env`, `*.env`), runtime uploads (`backend/uploads/*`), or dependency folders (`node_modules/`).
- Use clear and descriptive commit messages summarizing the changes made.
